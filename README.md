# Proyek Sistem Pengelolaan Data Siswa (SDN Slumbung 01)

Selamat datang di repositori **Sistem Informasi Akademik SDN Slumbung 01**.  
Proyek ini dikembangkan sebagai bagian dari **Ujian Tengah Semester (UTS)** mata kuliah **Pemrograman Web**.

Aplikasi dibangun menggunakan **PHP Native** dengan pola arsitektur **Model-View-Controller (MVC)**, serta telah berhasil di-*deploy* secara *serverless* melalui **Vercel** dan terhubung ke **database cloud (Railway)**.

---

## 🎯 Tujuan Utama UTS

Proyek ini telah memenuhi seluruh ketentuan penilaian UTS, meliputi:

1. **Struktur MVC Lengkap** — Pemisahan logika (Controller), data (Model), dan tampilan (View).  
2. **Fitur Login dan Registrasi** — Otentikasi berbasis PHP dengan validasi input dan hashing password.  
3. **Deployment ke Vercel** — Aplikasi berjalan *live* dan terhubung langsung dengan database *cloud*.

---

## 🚀 Fitur dan Teknologi

| Komponen | Deskripsi | Keterangan |
| :--- | :--- | :--- |
| **Arsitektur** | **MVC (Model-View-Controller)** | Struktur modular dan mudah dikembangkan. |
| **Database** | **MySQL (Railway)** | Basis data *cloud* dengan koneksi melalui PDO. |
| **Hosting** | **Vercel** | Platform *serverless* untuk menjalankan PHP *runtime*. |
| **CRUD Data Siswa** | Tambah, Edit, Hapus, dan Tampilkan Data | Dilengkapi fitur *search* dan *pagination*. |
| **Upload Foto** | **Cloudinary API** | Menyimpan foto siswa menggunakan *public ID* dari Cloudinary. |
| **Autentikasi** | **Login / Logout / Registrasi** | Validasi sesi berbasis PHP murni. |
| **UI Interaktif** | **SweetAlert2 + Bootstrap 5** | Notifikasi aksi dan tampilan modern. |

---

Proyek telah berhasil di-*deploy* secara penuh dan siap diuji.
